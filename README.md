## Overview

This project demonstrates the development of an interactive Student Details Dashboard using Microsoft Power BI. The dashboard provides insights into student enrollments, course completion status, payment analysis, age group distribution, and monthly course trends through dynamic visualizations and filters.

## Objectives

* Analyze student enrollment data effectively.
* Track course completion performance.
* Monitor payment amounts by course.
* Understand student demographics through age group analysis.
* Provide interactive filtering and reporting capabilities.

## Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX Measures
* Data Modeling
* Interactive Visualizations

## Dataset Information

The dataset contains:

* Student Information
* Course Details
* Enrollment Records
* Payment Data
* Course Completion Status
* Age Group Information
* Join Date Details
